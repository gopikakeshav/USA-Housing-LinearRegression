# USA-Housing-LinearRegression
### Modeling Housing prices using Linear Regression 

This is a short and sweet ML Pipeline that trains the House price dataset from [Kaggle](https://www.kaggle.com/datasets/quantbruce/real-estate-price-prediction/data) using LinearRegression from Scikit-Learn.

## Objective:
To model the data and create a ML pipeline that can be reused for future datasets.
